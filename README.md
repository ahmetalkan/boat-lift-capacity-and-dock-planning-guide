# Boat Lift Capacity and Dock Planning Guide

A waterfront owner reference for calculating full wet boat weight with safety margin, checking water depth and tidal range, confirming shoreline permits, and inspecting stainless cables and electrical GFCI gear citing USCG, NOAA, and US EPA.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — boat lift capacity and waterfront planning overview: `https://ahmetalkan.github.io/boat-lift-capacity-and-dock-planning-guide/`
- Subpage — tallying full wet boat weight plus capacity margin: `https://ahmetalkan.github.io/boat-lift-capacity-and-dock-planning-guide/wet-weight-and-lift-capacity.html`
- Subpage — verifying low-water depth, cradle clearance, and shoreline permits: `https://ahmetalkan.github.io/boat-lift-capacity-and-dock-planning-guide/water-depth-tides-and-pilings.html`
- Subpage — inspecting stainless cables, pulleys, anodes, and electrical safety: `https://ahmetalkan.github.io/boat-lift-capacity-and-dock-planning-guide/lift-cables-and-seasonal-care.html`

It cites public pages on [boatliftlabs.com](https://boatliftlabs.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
